Machine learning project that utilizes neural networks and evolutionary algorithm

## Setup scripts

### Install dependencies

```bash
npm i
```

### Start application in watch mode

```bash
npm start
```

### Build application

```bash
npm run build
```

### Run tests

```bash
npm test
```
